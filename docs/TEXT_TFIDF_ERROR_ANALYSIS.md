# Text TF-IDF 验证集错误分析

> 日期：2026-08-13  
> 数据：Validation Cold  
> 最终 Test Cold：未读取

## 1. 主要结论

标题信号真实存在，但效果高度依赖用户历史丰富度。近重复标题会制造少量“特别容易”的案例，却不足以解释总体增益。模型的主要失败来自历史过短、表达变化、跨语言内容以及视觉信息缺失。

## 2. 历史长度分层

| 训练期历史长度 | 用户数 | Recall@10 | NDCG@10 | HitRate@10 |
|---|---:|---:|---:|---:|
| 1–3 | 4,333 | 0.0841 | 0.0516 | 0.1101 |
| 4–6 | 6,126 | 0.1289 | 0.0811 | 0.1438 |
| 7–10 | 2,025 | 0.1663 | 0.1107 | 0.1990 |
| 11+ | 1,266 | 0.2123 | 0.1455 | 0.3073 |

这是一种相关关系，不是因果结论。高活跃用户可能同时具有更稳定、更容易预测的兴趣，不能仅凭该表断言“多收集几条历史必然使指标提升到对应水平”。

## 3. 近重复标题影响

定义：正例标题与同一用户任一训练历史标题之间的词集合 Jaccard 相似度。

- Jaccard ≥ 0.5：170 / 18,508 个正例（0.92%）。
- Jaccard ≥ 0.8：60 / 18,508 个正例（0.32%）。
- 排除 Jaccard ≥ 0.8 的正例后：Recall@10 = 0.12478、NDCG@10 = 0.07870、HitRate@10 = 0.15294。
- 原始结果：Recall@10 = 0.12797、NDCG@10 = 0.08211、HitRate@10 = 0.15636。

因此近重复会抬高结果，但不是主要解释。

## 4. 代表案例

### 合理主题命中

用户历史包含 `# TheFifth personality ...`，新视频 `# theFifth personality` 排名第 1。模型通过 `thefifth` 和 `personality` 识别稳定游戏主题。这是可解释的内容兴趣，但也非常依赖明确标签。

### 模板化命中

多名用户历史反复包含 `thank you ... babies ... company ... good evening`，模型将相似的新直播标题排第 1。这可能是同主播或同系列内容，属于现实中有价值的续看信号，但不能代表广泛语义理解。

### 自信但错误

某用户历史是“王者荣耀—马超”，模型首先推荐几乎相同的马超标题；用户实际正例是“王者荣耀—芈月”，只共享 `king/glory`，排名第 141。模型过度锁定具体英雄，无法理解用户可能偏爱更宽泛的游戏类别。

### 无文字输入信号

部分历史标题保留中文，而当前正则仅保留英文数字词，用户画像变成空向量，排序退化为随机。另一些失败即使是英文，也因历史与正例没有共同词而得到零相似度。

## 5. 总体失败规模

- 2,350 / 18,508 个正例的文字相似度为零，约 12.7%。
- 用户最佳正例的平均排名约为 430 / 1,305；虽然头部命中明显优于随机，仍有大量正例排在后部。
- 只有 5 名用户对全部候选均无法产生分数，但单个正例无词汇重合的问题更普遍。

## 6. 对产品方案的含义

1. 低历史用户需要更宽泛的类别、热门或探索策略，不能只依赖个性化标题相似度。
2. 高历史用户可使用更精细的兴趣画像，但要避免被单一重复主题完全锁死。
3. 推荐列表需要多样性或探索护栏，降低模板化内容霸榜风险。
4. 视觉模态的合理假设是补充跨表达和无文本信号，而不是简单追求更复杂模型。
5. 原始中文标题若实际可获得，应优先采用多语言分词或字符 n-gram；当前英文翻译文件限制了语言结论。

## 7. 决策

**进入 Visual-only 封面基线，但保持最小范围。** 下一阶段只下载约 0.62GiB 的官方封面包，先检查文件数量、ID 对齐、损坏率、尺寸和近重复图像风险。审计通过后才提取视觉特征；仍不下载关键帧、完整视频或音频。
