# ColdLens 公开 Demo 数据边界

> 决策日期：2026-08-17
> 状态：安全公开版已上线；真实标题驱动的本地 Demo 不直接部署公网

## 1. 核查来源

- [MicroLens 官方 GitHub 仓库](https://github.com/westlake-repl/MicroLens)
- [MicroLens 官方数据门户](https://recsys.westlake.edu.cn/)
- [MicroLens-50K 官方 readme](https://recsys.westlake.edu.cn/MicroLens-50k-Dataset/readme.txt)
- [MicroLens 论文](https://arxiv.org/abs/2309.15379)

## 2. 已确认的事实

1. 官方 GitHub 要求使用数据集或代码时引用论文。
2. 官方 GitHub 明确禁止私自修改数据集并提供二次下载，并鼓励公开数据处理代码或联系作者。
3. 官方数据门户对视频内容限定为学术研究与教育用途，禁止商业、营利或其他非学术用途；未经明确许可，不得修改、二次创作或分发视频内容。
4. 50K readme 只说明目录和字段结构，没有提供一份独立开放许可证来授权标题、交互记录或派生数据的公开再分发。
5. 已查阅的官方材料没有明确授权在求职网站中重新发布标题子集、用户序列或可下载的稀疏向量。

## 3. 当前风险判断

本地 `demo/public/demo-data.json` 包含 1,305 个 Validation 候选的标题与稀疏向量、360 条训练期历史标题与向量、8 个匿名用户样例，以及 IDF 和参考排序信息。即使去掉原始 ID，它仍是机器可读的数据子集和派生特征集合。

求职作品集不一定属于官方条款所指的学术研究或教育用途。因此，在没有书面许可前，把这份文件随网页公开下载存在不必要的数据再分发风险。这里采用保守的工程发布判断，不构成法律意见；若要公开真实标题版，应先取得数据权利方的书面许可。

## 4. 当前发布决策

可以公开：

- 本项目自写的源代码、配置、实验协议、系统设计和产品文档；
- 不可反推单条记录的聚合指标与自制图表；
- 数据处理和复现脚本；
- 完全自写的合成标题、合成历史和机制示例；
- 对论文和官方数据入口的引用。

不公开：

- 原始交互、标题、评论、点赞或播放统计；
- 视频、封面或其他媒体；
- 可重构真实样本的向量、IDF 或逐候选排序数据；
- `demo/public/demo-data.json`；
- 即使匿名化，仍来自真实数据的用户历史、候选池或逐用户推荐结果。

## 5. 安全公开版 Demo 设计

公开版分成两层：

1. **实验证据层**：展示冻结的聚合指标、Text/Visual 对比、三个融合方案被拒绝的原因，以及成本和证据边界。
2. **机制解释层**：使用完全自写的合成标题、合成历史和小型候选池，演示“历史标题 → 兴趣表示 → 相似度排序 → 推荐解释”的流程。

页面必须明确标注：

- 合成示例不是 MicroLens 原始或改写样本；
- 合成排序只用于解释机制，不是新的实验结果；
- 聚合实验指标来自 MicroLens-50K 离线研究；
- 页面不提供真实数据或派生数据下载。

真实标题驱动的完整版继续保留在本地，仅供本人离线检查和演示。

## 5.1 实现状态

- 安全公开数据已实现于 `demo/app/public-demo-data.ts`；
- 共提供 12 类、96 个可点击兴趣词、48 条合成历史与 72 个合成候选；
- 普通本地地址默认展示安全版，显式添加 `?local=1` 才读取被忽略的本地完整版；
- Vite 开发环境可读取 `demo/public/`，生产构建只复制 `demo/public-safe/`；
- 分享预览图为本项目自制资产，不包含真实数据或第三方媒体。

## 6. 发布前自动检查

- `demo/public/demo-data.json` 必须保持 Git 忽略；
- `data/`、`artifacts/` 和 `outputs/` 不得进入公开仓库；
- 公开构建流程不得复制本地真实 Demo 数据；
- 数据入口只链接官方页面，不创建镜像下载；
- README 与页面必须同时声明引用、用途和结果边界。
