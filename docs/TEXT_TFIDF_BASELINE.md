# Text-only TF-IDF 标题基线

> 实验：`text_tfidf_validation_v1`  
> 日期：2026-08-13  
> 状态：仅运行 Validation Cold，最终 Test Cold 未读取

## 1. 这个模型做了什么

1. 将英文翻译标题转为小写英文单词。
2. 只用开发训练视频统计词频；常见词权重较低，区分性词语权重较高。
3. 将用户训练期评论过的视频标题向量相加，形成用户兴趣画像。
4. 计算用户画像与 1,305 个冷视频标题的余弦相似度。
5. 对每名用户完整排序全部冷候选，不采样负例。

它没有使用视频 ID 热门度、全局点赞/播放量、封面、验证期词频或任何测试数据。

## 2. 验证结果

| 模型 | Recall@10 | NDCG@10 | HitRate@10 |
|---|---:|---:|---:|
| Random（固定种子烟雾测试） | 0.00709 | 0.00363 | 0.00931 |
| Text TF-IDF | **0.12797** | **0.08211** | **0.15636** |

TF-IDF 的 Recall@10 约为单次 Random 结果的 18 倍。这说明历史标题中的词汇与用户后续评论的新视频标题之间存在较强关联，但还不是最终测试结论。

其他事实：

- 词表大小：9,453。
- 训练视频零向量：49 / 16,907。
- 冷候选零向量：4 / 1,305。
- 无法形成历史画像的验证用户：4 / 13,750。
- 所有冷候选得分均为零的用户：5 / 13,750。
- 本地单次运行约 10 秒，不需要 GPU。

## 3. 重复标题排查

- 与开发训练视频标题完全相同的冷候选：24 / 1,305（1.84%）。
- 冷候选池内部的额外重复标题：9 / 1,305（0.69%）。
- 正例标题与对应用户历史标题完全相同：42 / 18,508（0.23%）。

完全重复数量不足以解释主要增益。不过相近标题、共同标签和模板词仍可能贡献较大，这既可能是真实兴趣信号，也可能是平台内容模板或翻译造成的捷径。

## 4. 产品解释

当前证据支持：

> 用户过去产生评论互动的视频标题，可以帮助筛选其可能继续评论的新视频。

当前证据不支持：

- 标题模型能提升点击率；
- 标题模型能提升播放时长或留存；
- 标题模型对普通观看用户同样有效；
- 线上系统会取得同等幅度提升。

## 5. 技术限制

- 标题是英文翻译/转写，并非原始语言文本。
- TF-IDF 不理解语义、否定、词序和画面。
- 评论正例存在强选择偏差和缺失曝光信息。
- 当前只做验证集模型选择，不能查看最终测试结果。

## 6. 下一判断点

在下载封面前，先做一次验证集错误分析：抽查高分命中、错误推荐和完全无共同词的案例，判断模型利用的是可解释主题词、模板化标题还是异常数据。若信号合理，再进入封面下载与 Visual-only 基线。

该错误分析现已完成，见 `docs/TEXT_TFIDF_ERROR_ANALYSIS.md`。近重复正例不是主要增益来源；去除词集合 Jaccard ≥ 0.8 的正例后，Recall@10 仍为 0.12478。已满足进入封面数据审计的条件。
