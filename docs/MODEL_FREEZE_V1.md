# ColdLens 最终测试前模型冻结记录 v1

> 冻结日期：2026-08-14  
> 当前状态：一次性最终测试已于2026-08-14按本记录执行并锁定；不得修改模型后重跑新版本

## 1. 最终候选

最终候选冻结为 `text_tfidf_v1`：

- 标题：数据集提供的英文翻译/转写标题；
- token：小写ASCII字母与数字 unigram；
- 最小文档频率：2；
- IDF：只在对应训练窗口的视频上拟合；
- item向量：TF-IDF后L2归一化；
- 用户画像：对应训练窗口内历史item向量等权求和后L2归一化；
- 得分：余弦相似度；
- 并列：`seed 20260813 + user_id` 的确定性随机顺序；
- 不使用封面、用户ID参数、视频ID参数、点赞或播放量。

最终阶段使用 `final_train` 重建IDF、item向量和用户画像，不继承开发训练阶段的词表或画像。

## 2. 最终报告中的独立基线

除Text-only最终候选外，只运行已经冻结的Visual-only独立基线：

- MobileNetV3-Small `IMAGENET1K_V1` 576维单位向量；
- 用户画像为最终训练历史视觉向量等权求和并归一化；
- 完整Test Cold候选余弦排序；
- 不训练、不调参。

Random仅沿用已存在的固定种子管线烟雾结果。ID/UNK退化与Random并列逻辑相同，不包装为有效个性化模型。

## 3. 不进入最终测试的验证期模型

以下模型已在Validation被拒绝，不运行其Test模型指标：

- 五档Text–Visual全局rank fusion；
- 低Text最高分条件式门控；
- 三权重pairwise学习式晚融合。

这样避免根据Test表现推翻Validation选择或进行事后挑选。

## 4. 最终测试口径

- 使用`final_train`：323,736条交互、49,887名用户、18,212个视频；
- Test Cold：1,008个完整候选、13,810名合格用户、18,812个正例；
- 报告Recall/NDCG/HitRate @5/10/20/50；
- Text-only和Visual-only都额外报告冻结的`visual_clean_dhash0`敏感性集合；
- 清洁集合排除与final_train任一封面dHash相同的13个Test冷候选，并同步调整正例与用户分母；
- 不采样负例，不修改K，不更换主指标。

## 5. 测试后规则

- 每个冻结模型只运行同一实现的确定性复现，不搜索参数；
- 无论结果是否理想，不返回Validation修改模型后重跑Test；
- 结果解释限定为公开评论正反馈匹配，不声称CTR、观看时长、留存或线上因果提升；
- 第一评论时间不等于上传时间，继续明确标注模型侧冷启动与真实发布冷启动的差异。
