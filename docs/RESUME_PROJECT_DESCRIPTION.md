# ColdLens 简历项目描述

> 面向 AI 产品经理岗位。默认版本优先展示问题定义、实验决策和产品取舍，不把项目包装成完整短视频平台或已上线系统。

## 一、推荐标题

**ColdLens｜短视频冷启动推荐实验与产品决策**

可附信息：个人项目｜AI 产品经理｜2026.08

## 二、简历标准版（推荐）

**项目背景：** 针对新视频缺少历史交互、传统 ID 推荐信号不足的问题，基于 MicroLens-50K 设计内容驱动的模型侧 Item Cold-Start 推荐实验，并形成可交互本地 Demo。

- 审计 35.97 万条公开评论交互、5 万名用户与 1.92 万个视频，识别“评论时间不等于上传时间”“评论不等于点击/曝光”等数据限制，将项目从“新发布视频推荐”收敛为可验证的模型侧冷启动问题。
- 设计按时间推进的 Train/Validation/Test 协议、完整冷候选排序与双指标准入门槛；冻结方案后在 1,008 个 Test 冷候选、13,810 名用户和 18,812 个正例上进行最终评估，避免 Test 反复调参。
- 使用 AI 辅助完成 Text、Visual 及三类融合方案的实验实现与结果核验；Text Recall@10 达 0.12551，明显高于 Visual 的 0.04543，三类融合均未同时提升 Recall@10 与 NDCG@10，按事前规则停止进入主链路。
- 将实验结论转化为产品方案：选择低成本、可解释的标题匹配作为冷启动兜底，输出线上 A/B 指标与护栏、故障降级和监控设计；搭建本地 Demo，支持匿名实验样例、模拟历史画像和方案对比。

## 三、空间有限的三条版

- 基于 MicroLens-50K 构建短视频模型侧 Item Cold-Start 实验，完成 35.97 万条评论数据审计，识别上传时间缺失和评论选择偏差，收窄不受数据支持的产品叙事。
- 设计时间切分、全候选排序和冻结 Test 机制；Text Recall@10 为 0.12551，较 Visual 的 0.04543 表现更优，三类融合未通过 Recall/NDCG 双指标门槛并停止投入。
- 将结果转化为 Text 冷启动兜底、线上 A/B 指标/护栏及本地可解释 Demo，明确离线评论匹配不能直接推导 CTR、播放时长或留存提升。

## 四、招聘平台精简版

围绕短视频新内容缺少历史交互的问题，基于 MicroLens-50K 完成模型侧冷启动推荐实验。通过数据审计纠正“首次评论等于上传时间”的错误前提，设计时间切分、全候选排序、Validation 准入门槛和冻结 Test。Text Recall@10 达 0.12551，优于 Visual 的 0.04543；三类多模态融合均未通过双指标门槛，因此选择低成本、可解释的标题匹配作为当前产品兜底，并完成线上实验方案、风险护栏及本地交互 Demo。

## 五、一句话版本

通过严格时间切分和冻结 Test 验证短视频冷启动内容信号，基于效果与工程成本淘汰未达门槛的视觉融合，形成 Text-first 产品兜底方案和可解释 Demo。

## 六、可放在技能栏或项目末尾的关键词

## 七、根据岗位侧重点微调

### 偏 AI 产品经理

优先保留：问题重定义、方案准入门槛、失败方案淘汰、工程 ROI、线上指标与护栏。

### 偏推荐产品

优先保留：Item Cold-Start、全候选排序、用户历史分层、冷启动分流、探索兜底和线上 A/B。

### 偏技术产品

优先保留：时间泄漏控制、模型冻结、Text/Visual 特征链路、故障降级、监控和复现性。

不要为了匹配岗位同时堆满三套关键词。应根据职位描述保留最相关的 3–5 个能力点。

## 八、真实性与 AI 协作口径

- 可以写“使用 AI 辅助完成实验实现与 Demo”，但必须能够解释数据边界、评测规则、模型去留和核心数字。
- 不建议写“独立开发完整推荐系统”。当前完成的是冷启动离线实验、产品方案和本地展示层。
- 若面试官追问代码，应如实说明 AI 在代码生成、排错和文档整理中的参与，并重点讲本人能够负责的需求定义、验收标准、结果判断和风险控制。
- 在没有亲自理解讲解稿和关键流程前，不应把“实现模型”写成个人独立技术能力。

## 九、禁止写入简历的表述

- “基于用户点击历史”——数据是公开评论历史。
- “识别真实新发布视频”——缺少可靠上传时间。
- “提升 CTR / 播放时长 / 留存”——没有线上 A/B 结果。
- “多模态融合上线”——三类融合均在 Validation 被拒绝。
- “搭建完整抖音推荐系统”——当前是冷启动排序模块和本地 Demo。
- “Text 提升 176%”——虽然可以计算相对差异，但容易忽略基线、代理标签和绝对指标，简历优先展示两组原始数值。
